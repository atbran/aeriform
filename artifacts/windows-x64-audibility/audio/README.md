# Listening comparisons

48 kHz stereo WAVs, generated from the synth's own factory patches and deterministic MIDI.

- before: d40798c, before the audibility redesign.
- after: the new build, same saved four-second configs. Compare matching filenames. Dry is bit-identical.
- after-matched-to-before: new full-output files RMS-matched to the corresponding before files. Compare these to before to judge timbre separately from volume.
- returns: actual isolated-return monitor renders with three-second test windows, plus room coupling comparisons. The coupling files have room Output level zero; 0.2 and 0.5 are moderate settings. These windows differ from before/after, so use the named pairs within each group.

Limiter and unrelated global effects were disabled for these measurements. These are generated comparison files; human listening approval is pending.
